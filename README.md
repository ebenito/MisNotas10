# Mis Notas Pro
 App UWP - Windows 10 - VS2019

UWP App para tomar notas
 * C#
 * OneDrive
 * SQLite

Puede instalarse desde la tienda de Windows: https://www.microsoft.com/es-es/p/mis-notas-pro/9nblggh08mcr


## Modernización propuesta

Se añadió una guía técnica de migración en `docs/modernizacion-tienda-windows-android.md` para evolucionar la app UWP a una base moderna con soporte de Microsoft Store (incluyendo trial/pago), Android, mantenimiento multi-idioma y objetivo principal en .NET 10.
